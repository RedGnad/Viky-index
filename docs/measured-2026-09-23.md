"error code: 1010", HTTP 403) and throttles wide calls beyond a few a second (429); `monad.drpc.org` caps at 10,000
blocks on its free tier.

## The indexer, run on a build VM

`config.rpc.yaml` (rpc1, a fixed 100,000-block batch, a two-second wait after a throttle), envio 3.12.1, on a plain
Debian 12 VM with Docker, Node 22 and pnpm. Run of 05:08 UTC (`artifacts/run-2026-09-23-0508/`): the indexer reached
the chain head 134 s after starting, `_meta.isReady` true, 84 events processed (the 102 logs less the 18 ownership,
pause, signer and gas events the index leaves out by design).

Earlier runs the same morning, each ended and its VM deleted: the handler file did not load without
`"type": "module"` (Envio v3 requires it); Envio's sequential sync over the 100-block endpoint measured 20 blocks a
second (45 hours to the head); its batch shrinking on every throttle (0.8 a miss) crawled at 300 blocks a second;
`backoff_multiplicative: 1.0` is refused; before its first batch `_meta` answers `progressBlock -1`.
